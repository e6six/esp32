# 📟 ESP32-2432S028 (CYD 2.8") — 10 Настольных Часов, Календарей и Погоды в 1 клик

Готовый веб-сайт специально для жёлтой платы **ESP32-2432S028 (320×240, сенсорный экран)**.
Позволяет прямо из браузера (Chrome / Edge / Яндекс.Браузер / Opera) в 1 клик заменить заводскую прошивку или **Bruce 1.11.1** на 10 автономных настольных виджетов (календари, часы, погода по Wi-Fi, таймер и органайзер).

---

## ⚡ Быстрый старт (всего 2 команды, без `npm install`!)

Всё необходимое (включая браузерный прошивальщик `esptool-js` и готовый графический движок LVGL 9.4 `cyd_lvgl_engine.bin`) уже встроено в проект.

### 1. Скачайте проект:
```bash
git clone -b arena/0c74c634-esp32 https://github.com/e6six/esp32.git && cd esp32
```

### 2. Запустите сайт:
```bash
node server.js
```
*(На Windows можно также просто дважды кликнуть по файлу `start.bat`)*

Откройте в браузере: **`http://localhost:3000`**

## Актуальные время и погода на плате

После установки обновлённого пакета виджетов плата подключается к указанной при прошивке сети **Wi-Fi 2,4 ГГц**, получает время по NTP и погоду по координатам из Open-Meteo. Повторная попытка выполняется примерно каждые 5 минут; доступ к UDP 123 и HTTPS должен быть разрешён. Часовой пояс задаётся числовым смещением в настройках, автоматического перехода на летнее время нет. Для обновления выберите виджет и заново запишите пакет через сайт; базовый движок повторно прошивать не требуется, если он уже установлен.

Без сети отображаются сохранённые при установке данные, а после полного отключения питания время может сброситься к моменту установки. Индикатор `OFFLINE / CACHED` не означает успешную синхронизацию. При проблемах подключите последовательный монитор на 115200 бод и проверьте сообщения `CYD_WIFI_ERR`, `CYD_NTP_ERR` и `CYD_WEATHER_ERR`. При работающем Wi-Fi, но недоступном погодном сервисе отображаются последние имеющиеся данные. Сервер и домен для этого не нужны. На реальной плате поведение зависит от установленной сборки MicroPython и доступности сети.

Для пересборки образа: `python -m pip install littlefs-python`, затем `python tools/build_vfs_image.py`. Пароль Wi-Fi записывается в память платы; не публикуйте дамп её флеша.
