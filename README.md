# 📟 ESP32-2432S028 (CYD 2.8") — 10 Настольных Часов, Календарей и Погоды в 1 клик

Готовый веб-сайт специально для жёлтой платы **ESP32-2432S028 (320×240, сенсорный экран)**.
Позволяет прямо из браузера (Chrome / Edge / Яндекс.Браузер / Opera) в 1 клик заменить заводскую прошивку или **Bruce 1.11.1** на 10 автономных настольных виджетов (календари, часы, погода по Wi-Fi, таймер и органайзер).

---

## ⚡ Быстрый старт (всего 2 команды, без `npm install`!)

Всё необходимое (включая браузерный прошивальщик `esptool-js` и готовый графический движок LVGL 9.4 `cyd_lvgl_engine.bin`) уже встроено в проект.

### 1. Скачайте проект:
```bash
git clone -b arena/0c74c634-esp32 https://github.com/e6six/esp32.git && cd esp32
```

### 2. Запустите сайт:
```bash
node server.js
```
*(На Windows можно также просто дважды кликнуть по файлу `start.bat`)*

Откройте в браузере: **`http://localhost:3000`**

---

## 🕰️ 10 встроенных вариаций часов, календарей и погоды:

1. 📅 **Классический Настольный Календарь на Месяц + Часы + Погода**
2. 🕰️ **Гигантские Flip-Часы во весь экран + Дата и Температура**
3. 📆 **Отрывной Календарь Дня (крупное число в ретро-стиле)**
4. 🌤️ **Домашняя Метеостанция (погода Open-Meteo по Wi-Fi без API-ключей + Мин/Макс)**
5. 📝 **Органайзер Дня: Часы + Погода + 3 ваших дела/напоминания с сайта**
6. 🌍 **Мировое Время (3 часовых пояса: Ваш город, Лондон/UTC, Токио)**
7. ⏳ **Счётчик Дней до События / Праздника + Часы**
8. 🍅 **Сенсорный Таймер Фокуса Помодоро (25:00) + Настольные Часы**
9. 🌙 **Прикроватные Ночные Часы (мягкий янтарный цвет, не слепящий ночью)**
10. 🔄 **Карусель «Все 9 Часов и Календарей по кругу»** (автосмена + переключение пальцем по сенсорным кнопкам `< PREV` и `NEXT >` внизу экрана!)
